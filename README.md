# Bipedal Press website

Plain HTML and CSS, hosted free on GitHub Pages at https://bipedalpress.com.

## Where things are
- `index.html` is the front page. `about/index.html` and `submit/index.html` are the other pages.
- `style.css` holds all the colors and type. The oxblood accent is `--accent` at the top.
- `images/` holds the artwork and photos.
- `site.js` switches on GoatCounter visitor stats once you add your code.
- `CNAME` (created by GitHub) holds the custom domain. Don't delete it.

## Common edits
- Change text: open the page, click the pencil icon, edit, commit. The site updates in a minute or two.
- Swap a photo: upload a new image with the same filename into `images/`.
- If you add a new page, add it to `sitemap.xml` too.
